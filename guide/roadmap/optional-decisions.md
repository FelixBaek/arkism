# 선택 카드 결정 기록

Task: R0; DYN-04; FLOW-01; MEAS-WL; PSY-TEAM-01; ASSOC; STRUCT; ADAPT
Research: 선택 범위와 재검토 조건 기록. 실험 결과가 아니다.

현재 63개 카드는 **필수 49개와 선택 14개**다. 최초 작업 계획부터 DYN-04는 선택이었다. 앞선 대조 보고서의 필수50·선택13 분류는 이 카드 하나를 누락한 수치이며, 원 보고서는 당시 감사 이력으로 보존한다. 이 정정은 개발 범위를 늘리거나 완료 수를 바꾸지 않는다.

아래 14개는 현재 구현·제품 채택을 보류한다. 기존 기능은 유지하고, 각 카드에 필요한 근거가 생기면 다시 검토한다. 자료가 아직 없다는 이유로 효과가 없다고 기각하지 않는다. 과거 다른 모델의 기각 결과도 이 실험에 이월하지 않는다.

| 카드 | 현재 결정과 이유 | 재검토 조건 |
|---|---|---|
| DYN-04 | 보류 — capture 확장 비교와 검토된 수치 계약이 아직 없다. | scalar/fastslow 대조와 초기 pilot에서 필요성을 확인한 뒤 재검토한다. |
| ASSOC-01 | 보류 — 별도 회수 질문과 encoder·출처·삭제 계약이 미확정이다. | 기존 검색을 재사용해 독립 질문과 계약을 먼저 검토한다. |
| ASSOC-02 | 보류 — 반복 reader의 선행과 명시적 반복·예산 계약이 없다. | ASSOC-01 이후 강한 one-step 대조와 중단 조건을 검토한다. |
| ASSOC-03 | 보류 — paired 비교 자료와 선택 기준이 없다. | ASSOC-02 이후 동일 후보·전체 비용의 별도 비교가 필요하다. |
| STRUCT-01 | 보류 — 독립 의미 라벨과 unknown 기준이 미확정이다. | 기존 advisory 분류와 사람 승인 경계를 대조로 유지한다. |
| STRUCT-02 | 보류 — 검산할 수학 계약과 한 가지 방법이 미선택이다. | STRUCT-01 이후 작은 검산 예와 의미 효용을 분리한다. |
| STRUCT-03 | 보류 — 정답·검토 예산·선행 진단이 없다. | 같은 검토 예산에서 추가 가치를 비교한 뒤 판단한다. |
| ADAPT-01 | 보류 — train 라벨·특징 가용 시점·분할·모델이 미선택이다. | frozen 비교군이 필요해지면 재검토하며 전체 EXP02 종료를 불필요한 선행으로 삼지 않는다. |
| ADAPT-02 | 보류 — frozen 대조와 온라인 상태·갱신 예산 계약이 없다. | ADAPT-01 이후 scope별 상태와 중복 갱신 방지를 검토한다. |
| ADAPT-03 | 보류 — 온라인 모델을 선택하지 않았다. | 온라인 도입 전 삭제 영향 제거·retained-data 재구축은 필수다. |
| ADAPT-04 | 보류 — 비교할 온라인 구현·별도 질문·측정 자료가 없다. | 튜닝·갱신·삭제·복원까지 포함한 전체 비용으로 비교한다. |
| FLOW-01 | 보류 — 재사용할 FLOW/CRW 가상 실행은 있지만 별도 선택기 비교·잠금·추가 가치가 미확정이다. | 현재 같은 fixture를 더 만들지 않고, 독립 선택 질문과 검증 정책이 정해질 때 재검토한다. |
| MEAS-WL | 보류 — 연구자의 부담 질문·자기보고 척도 선택이 없다. | 연구자가 선택할 때만 계산·결측 명세를 준비한다. 실제 수집은 별도다. |
| PSY-TEAM-01 | 보류 — PSY05 결과와 좁은 팀 연구 질문이 없다. | 선행 결과 뒤 질문 하나의 문서·합성 trace부터 검토한다. |

부담 척도·연구 계수·참여자 수·라벨·효과를 임의로 정하지 않았다. 노출을 실제 사용으로, 관측 결과를 인과 공로로, 같은 출력 hash를 삭제 완결로 바꾸지 않는다. 무제한 자기수정·새 승인 권한·gold 누출을 요구하는 구체 안은 수용하지 않는다.

이 기록은 14개 선택 카드의 현재 결정이다. 필수 작업이나 선택지의 효과 검증 완료가 아니며, 선택 보류를 완료 카드에 더하지 않는다. 최신 필수 카드 집계는 [진행 기록](progress.md)을 따른다. 현재 필수49개 중30개 검증 완료·19개 미완료이며 선택14개 보류는 변하지 않는다.

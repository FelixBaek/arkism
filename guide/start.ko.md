# 처음 시작하기

Arkism을 처음 설치한 뒤 기억 후보가 모이기까지의 순서예요. 앱 화면에 나오는 말 그대로 적었어요.

## 1. 설치하고 고르기

1. [Releases](https://github.com/FelixBaek/arkism/releases/latest)에서 설치 파일을 받아 설치해요. 지금은 Windows 설치 파일만 있어요.
2. 앱을 열면 **Arkism을 어디서 쓸까요?** 화면이 나와요.
   - **이 PC에서 쓰기**: 대부분은 이것을 고르면 돼요. 기억은 이 PC에만 저장돼요. **시작**을 누르면 끝이에요. 저장 폴더를 바꾸고 싶을 때만 **자세히 (저장 위치)**를 열어요.
   - **서버에 SSH로 연결**: 여러 PC가 같은 기억을 써야 할 때만 골라요. 서버에 Arkism이 먼저 설치돼 있어야 해요. [서버에 설치하기](server.ko.md)를 보세요.

처음 켤 때는 1분쯤 걸릴 수 있어요. 켜지지 않으면 **다시 시도**를 누르고, 그래도 안 되면 **점검하고 고치기**를 눌러요. 문의할 때는 **기록 폴더 열기**로 연 폴더의 파일을 같이 보내 주세요.

## 2. 홈의 「시작하기」 네 줄

기억이 하나도 없을 때 홈 맨 위에 **시작하기**가 보여요. 네 줄이 모두 준비되면 대화에서 기억 후보가 모여요.

| 줄 | 할 일 |
| --- | --- |
| 에이전트 연결 | 앱이 처음 켜질 때 Claude Code·Codex 같은 에이전트 설정 파일에 Arkism을 이어 둬요. 바꾸기 전 파일은 백업 폴더에 남고, 그 경로가 여기 보여요. 열려 있던 에이전트는 다시 시작하세요. 실패했으면 **다시 연결**을 눌러요. |
| 기억 뽑을 모델 | 대화에서 기억 후보를 뽑는 모델이에요. 로그인된 Claude Code, Codex, Gemini CLI 중 하나를 앱이 스스로 골라요. **로그인 필요**가 보이면 **로그인하기**를, 답을 못 읽는다고 나오면 **다른 모델 고르기**를 눌러요. |
| 평소처럼 대화하기 | 에이전트와 평소처럼 대화하면, 대화가 끝나고 몇 분 뒤 후보가 홈에 와요. |
| 기존 지침 파일 가져오기 | 에이전트 지침 파일에 이미 적어 둔 규칙을 후보로 가져와요. 먼저 몇 개인지 보여 주고, 가져온 것은 검토 대기로 가요. |

그 아래 줄은 PC에 로그인할 때 Arkism이 트레이에서 자동으로 켜지는지 알려 줘요. 앱이 꺼져 있으면 대화를 모으지 않아요. 원하지 않으면 **끄기**를 눌러요.

## 3. 승인하기

후보는 저절로 저장되지 않아요. 홈의 **기억 검토**나 **MEMORY**에서 맞는 것만 승인하면, 다음 대화부터 에이전트가 그 기억을 써요.

## 문제가 생기면

- 상태 카드(왼쪽 아래 아이콘)에는 설치된 에이전트만 보여요. 설치하지 않은 에이전트는 문제로 세지 않아요.
- **기억 뽑을 모델** 줄이 상태 카드에 보이면, 후보가 왜 안 오는지 그 줄이 알려 줘요.
- 설정 › 고급 › 진단의 **점검**과 **고치기**로 연결·에이전트·수집 상태를 확인할 수 있어요.

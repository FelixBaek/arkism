# Actual native execution recording and fresh replay reconciliation

Task: EXP-02 (#153), consumed by EXP-03/EXP-04 (#153)
Research: Offline synthetic execution provenance and reproducible analysis; no empirical acceptance.
Design: A separate recorder consumes the actual typed plan and unexecuted index, fixed projection/analysis/schedule, explicit roots, existing native executable and an independently pinned execution dispatch. The dispatch binds the exact plan/index/projection/program and declared attempts. Preflight reads the actual plan ArtifactRef and all native/source/owner inputs, validates the original wire and schedule, and checks exact fixed native argv and fresh output paths. It performs no native child invocation. Only after these checks does recording begin. Final REF validation, when required, starts after a durable journal entry under the shared deadline and has separate replay evidence and explicitly unmeasured process counts. The unchanged argv is passed to subprocess with executable= a private byte-pinned image snapshot; image identity is explicit in the journal. Each attempted run preserves raw bounded stdio, truncation sizes, monotonic timestamps in one unique process clock, real exit/timeout/interruption, per-attempt checkpoints and exact observed nonadditive elapsed time. Unmeasured declared costs remain missing, never zero or a divided batch cost. Only original Go fresh replay plus full source/prediction/denominator/stdout reconciliation permits a completed row. The initial index is unchanged; the recorded original typed index and updated projection are separate artifacts.
Relation: partial

Multiple independent retry/duplicate outputs need an explicit wire sidecar extension, not overwriting prior results or hiding attempts. It does not implement that extension yet. The primary selection rule already remains first-completed elsewhere. A pending dispatch journal is not a start receipt, and a killed host or unexpected fatal interruption may require explicit checkpoint recovery; no successful final index is fabricated. Owner declaration bytes and explicit local fixture dispatch do not authenticate a human or scientific permission. The original builder's unassigned acceptance gates stay pending.

Design: The separate producer consumes the original dataset/manifest, analysis plan and schedule, byte-preserved analysis-source, explicit synthetic admission catalog, registry, materialization controls and explicit owner ArtifactRefs. It validates original semantic/split rows and exact events/queries/gold raw hashes, requires all seven native policies, and invokes the label-free materializer with each source QueryPlan. Gold stays in the evaluator-side source-view mapping and never reaches ranking or native feature generation. Typed native jobs cover each scheduled query/repetition with exact scope, budget, source/native time, cutoff and candidate hash. A mismatch in explicit final-k rejects instead of rewriting it. The original RunPlan/RunIndex DTOs and v1 builder are unchanged. Initial rows are not_run with no successful prediction or invented execution receipt. A projection plan preserves the user-selected first-completed policy. The CLI publishes a new owned produced subtree with directory descriptors, inode checks and exact tracked-file cleanup; foreign content and existing outputs are preserved. The compiler counts policy processes separately from its explicitly pinned Go hash callback; the CLI reports the one hash-stream process it actually started.

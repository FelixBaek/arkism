# EXP-03 native replay verification

Task: EXP-03 (#153), DYN-05 (#152)
Research: Exact offline execution evidence for paired analysis, not a new quality or user-effect result.
Design: Extend the existing native producer CLI with a read-only verify command. Reuse its accepted strict Go loader/codecs and actual deterministic policy replay, comparing every stored prediction/failure/cost with recomputation. Emit a separate verification sidecar with original raw input/completion/prediction identities and semantic config/registry bindings. No frozen native/v1 DTO or codec is modified. DYN05 owns the producer files, EXP03 consumes them, and root is the sole writer in this isolated worktree.
Relation: partial
Deviation: This implements the native-engine proof step needed by the formal EXP02-to-EXP03 projection. The plan/run-index, replication/history/gold/budget/cost mapping and final-lock authority binding remain engineering work. A verification report is not scientific approval or actual product authority; both flags remain false.
Why: The existing Python comparison reader supports only a subset of native types and checks declared commitments. Copying/extending that parser would not prove actual replay. The existing Go engine already owns strict validation and deterministic selection; the new command reuses it and rejects even a correctly resealed wrong selected-memory result.
Verified: The native command package passed 19 top-level tests with race detection, including its original run regressions and new verify tests. A focused strengthened functional test also verifies actual B0 refs a,b and packing cost 4, with all source/result file hashes unchanged. Both plain and P1 paths execute; plain mode retains exactly one missing-feature IR failure across seven policies. P1 feature raw-byte/base semantic changes, raw corruption, output symlinks and correctly resealed wrong selections are rejected. The actual Unix FIFO opener does not block and readAt rejects the non-regular file. Pinned golangci-lint v2.14.0 passes. Windows and Darwin test executables cross-compiled and were removed; they were not executed. Two independent review axes found no remaining required issue after fixes. The original full check predating these changes passed separately as described below.
Limits: No whole-card or roadmap completion. Native result projection, actual labels, final scientific lock/trust and final whole-tree checks remain. No standalone CLI/product binary build, installation, operating DB, deployment, model request or new paid provider call. Non-Unix reader behavior is unchanged and cross-compilation is not runtime proof. The saved report alone cannot attest to its executor; the future formal adapter must invoke and bind the actual verifier.

Review/failure history: The first new test expected one probe, but the unchanged actual fixture has seven policy-specific probes. The test now checks seven and compares the complete probe object with the original strict-decoded input. Standards review found an inherited regular-file-to-FIFO blocking-open race in the shared reader; Unix NONBLOCK/NOFOLLOW open plus the existing inode/type fences fix it. Spec review initially misclassified the existing fixture as plain; the reviewer corrected that report after checking its actual P1 flag, and independent plain-mode and P1 graph-tamper coverage were added. Initial failures/reviews are preserved privately rather than overwritten or promoted to passes.

Scoped full-check evidence: The pre-verifier EXP03 analyzer/views snapshot completed check_local with exit0: actual PostgreSQL memory tests ran 481.428 seconds, Python suites passed 179/650/49 tests and frontend tests passed 591 (zero failures/skips). Its pinned source predates this verifier; the changed native main and added files are explicitly recorded, so that run is not current-tree full verification. The separate RTE tree had already passed its own full check. Only the owned disposable PostgreSQL cluster was cleaned after both runs: no remaining child DB/clients, fixture roles removed, server stopped and temporary cluster removed. The current verifier has its own race/lint/compile evidence above.

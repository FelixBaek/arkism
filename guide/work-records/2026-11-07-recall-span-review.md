# 근거 구간 중복 판정 수정

작업 ID: p14-review2
연구: 해당 없음

## 변경 이유와 동작

- 선택 반복문에서 같은 근거를 다시 토큰화하던 비용을 줄였다. 후보별 토큰 집합을 한 번만 만들고, 이미 최대 중복 벌점을 받은 후보는 이후 비교에서 건너뛴다. 포함률 비교도 작은 집합만 순회한다.
- 한 메시지의 넓은 인용은 서로 다른 사실을 함께 담을 수 있다. 근거 포함률만으로 최대 벌점을 주지 않고, 같은 검색 범위의 비교 가능한 벡터가 기존 중복 구간(코사인 유사도 0.92 이상)에 있을 때만 근거로 벌점을 강화한다.
- 짧은 쪽의 고유 검색 토큰이 네 개 미만이면 근거 포함 판정을 하지 않는다. 기존 벡터 벌점과 점수 원본은 유지한다.
- 근거 문자열은 계속 내부 필드로만 다룬다. 모델 호출·운영 서비스 변경·push는 하지 않는다.

## 검증

- 기존 소스에 새 회귀시험을 적용하는 오버레이와 수정한 소스의 실행 결과를 별도로 비교한다. 오버레이는 저장소의 기존 파일을 덮어쓰지 않는다.
- 단위시험은 같은 인용의 다른 사실, 벡터 없음·한쪽 없음·차원 불일치·영벡터, 근거 포함률 경계, 1~3개 고유 토큰, 네 개 토큰, 같은 토큰의 반복, 다른 범위, 응답에서 내부 근거 비공개를 확인한다.
- 성능 시험은 후보 100개·선택 50개·근거 2,000자, 동일 근거와 서로 다른 근거 두 경우를 사용한다. 입력 준비는 측정에서 제외한다.
- `systemd-run --user --scope -q -p MemoryMax=6G timeout 900 go test ./internal/memory -count=1 -bench BenchmarkSelectDiverseSourceSpan -benchmem`: 전체 패키지와 성능 시험 통과(90.226초). 같은 제한으로 다양성 관련 시험 20회 반복 통과(0.938초).
- 새 시험을 기존 소스에 적용하면 짧은 근거 4개 경우와 서로 다른 사실·벡터 부재 등 6개 경우에서 의도한 실패를 재현한다. 첫 시험 작성 때 비교 후보 점수가 기존 벡터 벌점만으로도 밀리던 문제는 두 벌점의 차이를 구별하는 점수로 수정했다.
- 같은 성능 시험을 기존 소스에 오버레이해 3회 측정했다. 서로 다른 근거는 269.8~356.2ms, 같은 근거는 285.7~373.0ms, 할당은 두 경우 모두 약 193.04MB·166.9만 회였다.
- 수정본을 별도로 3회 측정하면 서로 다른 근거는 19.5~24.8ms, 같은 근거는 3.7~4.3ms, 할당은 두 경우 모두 약 2.68MB·22,604회다. 합성 입력의 결과이며 운영 지연 시간으로 일반화하지 않는다.
- 벡터 부재·차원 불일치 때 근거 단독 벌점을 적용하는 비교 후보도 오버레이로 측정했다. 같은 인용의 다른 사실 보존 시험에서 양쪽 벡터 없음·첫 벡터 없음·둘째 벡터 없음·차원 불일치 네 경우가 실패한다. 따라서 비교 가능한 벡터가 없는 기억에는 근거 단독 벌점을 적용하지 않는다. 이 비교 후보의 전체 하네스는 잠금 대기 중 취소했고 실행하지 않았다. 복원 자료의 활성 기억 1,157개는 모두 벡터를 가지고 있어, 벡터 부재 동작은 별도의 합성 시험으로 판별했다.
- 고정 하네스 `run.sh`를 기존 잠금으로 실행한 `p14-review2-vector-required`는 정상 종료했다. `analyze.py`로 `p13r2-final`과 비교했다. 453개 고유 요청 키와 근거·분류가 모두 같고, 근거가 있는 451행에서 검색 저하 요청은 0이다.

| 분류 | 기준 R@10 | 수정 R@10 | 개선 행 | 손실 행 |
| --- | ---: | ---: | ---: | ---: |
| multi-hop | 0.5955 | 0.5955 | 0 | 0 |
| open-domain | 0.6146 | 0.6146 | 0 | 0 |
| temporal | 0.9109 | 0.9109 | 0 | 0 |
| single-hop | 0.9707 | 0.9707 | 0 | 0 |
| 전체 | 0.8565 | 0.8565 | 0 | 0 |

주 지표는 기억 항목과 함께 반환되는 대화 문맥을 합친 근거 회상률이다. 각 행에서 이전에 포함했던 정답 근거 ID가 빠진 경우도 0행임을 추가 확인했다. 모델 감지 로그 0줄, 비임베딩 모델 사용 기록 0→0이다. 평가 입력·하네스·검색 한도·문맥 예산은 변경하지 않았다.

보조 지표인 기억 항목만의 회상률은 multi-hop 0.4769→0.4787(개선 1행), single-hop 0.8515→0.8473(손실 1행), 전체 0.7491→0.7473이다. 해당 손실 근거는 대화 문맥이 계속 제공하므로 주 지표 손실은 없다. 이 변경을 모든 보조 지표의 무손실이나 회상률 향상으로 표현하지 않는다. 기존 후보의 주 지표 개선 2행은 이번 보수적 조건에서 유지되지 않는다.

## 한계

벡터와 근거를 함께 보아도 중복 판정은 휴리스틱이다. 고정 오프라인 자료의 근거 회상률은 답변 정확도나 운영 성능을 증명하지 않는다. 운영 배포 및 원격 게시 검증은 범위에 없다.

기준: `a4e629c`의 최신 main UI 병합 이후 변경. 대상 제품은 Windows이다.

## 변경 이유와 구현

기존에는 기억의 저장소·정렬, 후보·스킬의 검색·분류·에이전트·정렬이 읽은
페이지 안에서만 적용됐다. 자료는 500개, 목차는 200개, 세션 UI는 300개,
서버 세션 읽기는 20,000개, 개요 큰 창은 80개에서 잘렸다.

전체 권한 범위를 기준으로 필터·정렬한 뒤 페이지를 반환하는 POST 관리 쿼리
4개를 추가했다. 기존 GET 초기 요약과 권한·승인·삭제 계약은 유지한다.
커서는 scope·사용자·역할·쿼리·정렬·전체 결과 해시에 묶인다. 변경된 결과의
409 응답에서는 열린 페이지 창을 다시 읽는다. 권한이 바뀌거나 격리·삭제된
자료를 결과에 포함하지 않는다. 자료 목차는 현재 문서의 모든 경로를 검색하며
원문 조각 본문을 목록으로 노출하지 않는다. 지식 기능의 기존 gate도 유지한다.

Postgres 자료·바인딩·세션은 ID로 이어 읽는다. 세션의 모델 동률과 비용 합산
순서를 고정했다. 세션 검색·토큰/비용/메시지 정렬과 다음 커서를 추가했으며,
중복·미지원 쿼리 필드는 거절한다. 개별 세션의 도구·스킬 50개 잘림도 제거했다.

UI는 처음 50개를 읽고 명시적 다음 버튼에서만 추가한다. 자료·세션도 기존
가변 높이 가상화를 공유한다. 상세 선택, 새 스킬 페이지의 버전 검사, 타이핑
초점·커서, 연결 세대·scope 변경의 늦은 응답 폐기를 보완했다. 개요 큰 창에도
전체 쿼리와 다음 페이지를 연결했다. 홈·개요의 일부 통계와 후보/동명 스킬
묶음이 읽은 항목 기준인 점은 명시한다. 기존 카테고리·토큰·아이콘을 유지했다.

HTTP inline 라우트 83개를 도메인 등록 함수로 옮겨 `http.go`는 288줄이 됐다.
공통 인증 등록기·응답 보호·시간 제한은 유지했다. 업로드 동시 실행 제한은
업로드 라우터가 소유한다. `memoryd`는 명시적 옵션/모드, 환경 검증, 오프라인
관리, 서비스 구성, 실행 수명주기로 분리했다. 서로 배타적인 모드를 섞으면 DB를
열기 전에 거절한다. 복구는 HTTP/worker에만 허용한다. 기존 단일 플래그는 유지한다.

OpenAPI는 275개 운영 라우트, 관리 DTO manifest는 65개 연산이다. 새 쿼리의
입력 크기·상태·정렬과 세션 커서를 명시했다. Go 실제 HTTP 정상·익명·미지원
필드 corpus도 확장했다. 기존 Go AST exporter 결과를 입력으로 받는 옵션을
추가해 컴파일 없이 스키마를 갱신할 수 있다. 개발·서버·목록 설명을 최신화했다.

## 실행한 검증과 결과

- `node --test desktop/ui/*.test.js`: 17개 테스트 파일 통과.
- `node desktop/ui/catalog-query.test.js`: 새 직접 검증 5개 통과. 필터 유지,
  선택의 최신 데이터 우선, scope 전환, 409 재시작, 실패 시 이전 행 유지,
  재시도·잘못된 메타데이터·순환 커서를 포함한다. 여러 페이지 갱신이 중간에
  실패해도 전체 개수·분류 수가 기존 행과 함께 유지되는 회귀를 재현해 수정했다.
- 소스 UI의 실제 Chromium 5개 브라우저 시나리오 통과. 10만 기억의 미로딩
  검색·서버 종류 필터, 기존 7화면·키보드·언어 전환, 400행과 후보/스킬/휴지통,
  1만 가변 높이 행(최대 DOM 24개), 1,200개 자료/세션/개요의 미로딩 검색·전체
  정렬·추가 페이지·오류 보존·입력 초점을 포함한다. 외부 통신은 fixture로 차단했다.
- 사전에 존재하던 로컬 분석 실행 파일로 Go 소스를 파싱했다. 분석 도구를 새로
  컴파일하지 않았다. 복잡도 gate 통과, 기준표 변경 없음. `memoryd.run`은
  166→15, `handlerMode`는 3. 기존 20 초과 함수 379개는 여전히 보고한다.
- 사전 컴파일된 AST exporter로 현재 소스 DTO를 읽고 Python으로 OpenAPI를
  갱신했다. 275개 라우트 스키마/참조 및 65개 DTO 대응 검사 통과.
  이 검사는 실제 Go HTTP 응답 실행이 아니며, 이번 변경의 실제 응답 검증은 0건이다.
- OpenAPI Python validator 회귀 테스트 6개 통과.
- Better Design 로컬 코드 검사: `desktop/ui/memory-pages.css`, 발견 0개.
  위 Chromium 화면/키보드 검증과 별도로 실행했다.
- `gofmt` 구문 검사·정리, `git diff --check` 통과.
- Windows 전송 검토용 35개 공개 소스/API 파일을 별도 폴더에 준비했다.
  gitleaks 검사 통과. 아직 전송하지 않았다.

## 미실행과 한계

사용자가 ‘빌드 시작 전 질문’을 요청했으므로 Go 컴파일·Go 테스트·프런트 번들
빌드·Windows 설치파일 빌드는 실행하지 않았다. 새 Go 테스트는 전체 검색/정렬,
권한·격리·커서, 500개 이후 자료·200개 이후 목차, 20,000개 이후 세션,
500개 이후 스킬, 모드 충돌을 검증하도록 작성했지만 미실행이다.
Windows용 기존 테스트 전용 소스를 검증한 뒤 현재 35개 파일을 전송해 새 전용
폴더에서 테스트할 계획이며, 전송·빌드 승인을 먼저 받는다. 실제 앱/DB/설정은
변경하지 않는다. 원격 게시·PR·push도 실행하지 않았다.

서버 쿼리는 전체 권한 결과를 읽고 정렬하므로 비용·메모리는 결과 수에 비례한다.
대규모 실제 DB의 지연·메모리는 아직 측정하지 않았다. SQL/RLS 통합 검증과
Windows Go 실제 실행, 배포 번들의 브라우저 검증은 승인 뒤 별도로 기록한다.
새 서버가 없는 구버전에서는 전체 쿼리 기능을 사용할 수 없으며 오류를 표시한다.
자료·세션 외 위키 등 다른 도메인의 기존 계약은 변경하지 않았다. 서버 전체의
379개 복잡도 부채를 모두 해소한 것으로 표시하지 않는다.

커밋 상태: 최신 main UI 통합은 `a4e629c`에 로컬 커밋. 이 후속 구현은 빌드
승인·네이티브 검증 전 로컬 체크포인트로 보존한다. 원격 게시하지 않았다.

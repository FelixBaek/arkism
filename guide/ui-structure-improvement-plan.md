# UI 구조와 검증

2026-10-21의 추가 구현 요청을 반영한 현재 구조다. 화면 배치·제품 토큰·아이콘은
기존 것을 사용한다. 이 문서의 이전 ‘설명만’ 범위는 후속 요청으로 변경됐다.

## 진입과 조립

`desktop/ui/entry.mjs`가 의존 모듈을 명시적으로 불러오고, 처음 선택한 언어가
준비되면 `startApp()`을 실행한다. HTML의 개별 스크립트 60개 대신 `look.js`와
하나의 모듈 진입점을 사용한다. 모양 설정은 첫 그리기 전에 적용한다.

Windows 패키징은 `desktop/frontend/package-lock.json`의 esbuild 0.28.2로
조립한 `desktop/ui-dist`를 Tauri에 전달한다. 원본 개발 진입점과 동일한 모듈
그래프를 사용하며 영어 사전은 별도 동적 청크다. 의존 패키지·테스트·미리보기
자료·원본 스크립트는 배포용 자산에 복사하지 않는다. 출력 검사는 입력 해시,
HTML 참조 자산, 영어 청크 분리를 확인한다. 생성 폴더는 로컬 Git 제외 대상이다.

## 소유권

| 경계 | 소유하는 것 |
|---|---|
| `modules/state.mjs` | 연결·인증·scope·세대 번호, 화면별 필터, 기존 화면용 접근자 |
| `modules/appApi.mjs` | 네이티브/브라우저 전송, HTTP 상태·오류 코드, 이전 연결 응답 거부 |
| `modules/appConnection.mjs` | 잠금·로컬/서버 연결·SSH 입력·연결 해제 |
| `modules/collectionPaging.mjs` | 후보·충돌·스킬·휴지통의 개별 커서와 공통 더 보기/재시도 |
| `modules/virtualList.mjs`, `listFocus.mjs` | 측정한 행 높이·화면 주변 행·키보드 이동·초점/입력 커서 보존 |
| `modules/visibleSync.mjs` | 화면별 읽기 계획, 변경된 결과만 게시, 열린 페이지 범위 갱신 |
| `modules/candidateGroups.mjs`, `skillSimilarity.mjs` | 후보 묶음 지연 생성, 50개씩 넘기기, 비슷한 스킬 계산의 분할 실행 |
| `modules/memoryPaging.mjs` | 기본/검색 커서, 요청한 페이지 창, 별도 정리 제안 참조 캐시 |
| `modules/memoryList.mjs`, `memoryDetail.mjs` | 목록/필터/검토 동작, 상세/직접 기억 추가·수정 |
| `modules/skillViews.mjs`, `imageViews.mjs`, `designViews.mjs`, `toolViews.mjs` | 각 화면의 목록·편집·연결 동작 |
| `modules/crewEditor.mjs` | 현재 그래프·선택·좌표·변경 상태 |
| `modules/crewNodes.mjs` | 노드 설정 창·검사기·노드별 편집 |
| `modules/crewExecution.mjs`, `crewRunView.mjs` | 실행/승인/중단 명령, 조회 타이머·실행 화면 |
| `modules/crewReview.mjs` | AI 검토 제안·적용 전 대상 상태 확인 |
| `modules/crewWorkers.mjs`, `crewPersonas.mjs` | 전문가 초안·자료·기록, 페르소나 설정 |
| `modules/crewModel.mjs`, `crewVocabulary.mjs`, `crewSchedule.mjs` | 그래프 탐색·규칙, 노드 명세, 일정 해석 |

모듈은 명시한 의존 포트로만 다른 소유자에게 접근한다. 함수와 읽기 전용 값은
getter로 연결하고, 실제로 다른 소유자가 바꾸는 값에만 setter를 둔다.
`window`에 새로운 화면 상태를 추가하지 않는다. 기존 주변 화면의
`window.Arkism*` 팩토리는 진입 모듈 안에서 호환 어댑터로 유지한다.
기존 평면 state 접근자도 같은 소유 객체로 연결되어 복제 값이 생기지 않는다.

API 응답은 서버·토큰·scope·연결 세대가 바뀌면 버린다. 실행 조회는 타이머
세대와 편집 대상도 확인하므로 같은 실행 ID로 다시 들어와도 이전 조회가
새 편집기를 덮지 않는다. 잠금은 조회 타이머·그래프/전문가 초안을 초기화한다.
AI 검토도 다른 그래프나 연결로 넘어간 뒤 도착한 제안을 적용하지 않는다.

## 언어

한국어 시작에는 약 498KB의 영어 원본 사전을 요청하지 않는다. 영어 선택 시
한 번 불러오고, 로딩 중 다시 한국어를 선택하면 늦은 로딩이 언어를 되돌리지
않는다. 셸의 탭은 고정 메시지 ID로 바인딩한다. 아직 이전 화면에 남은 DOM
번역 어댑터는 사용자 원문·코드·편집 칸을 건너뛴다. 모든 문구를 메시지 ID로
변환했다고 주장하지 않는다. 모듈 안의 한국어도 기존 번역 누락 검사에 포함한다.

## 확인 범위와 한계

단위 검사는 화면별 상태 소유권, 연결 전환 후 늦은 응답, 실행 조회의 잠금·
화면 재진입·이동, 기억 추가/되돌림 결과를 확인한다. 실제 브라우저 검사는
`desktop/tests/ui-structure.browser.cjs`와 `memory-pages.browser.cjs`에 있다.
동일한 합성 자료·화면 크기·시각으로 이전 UI와 원본/배포용 UI를 비교한다.
실행 결과와 화면 증거는 해당 작업 기록에 남긴다. 실제 Windows WebView와
설치 프로그램을 다시 빌드·설치했다는 뜻은 아니다.

기억·후보·충돌·스킬·휴지통은 각각 첫 50개만 읽고, ‘더 보기’에서 다음
서버 커서를 요청한다. 갱신은 실제 읽은 페이지 수를 유지하며, 빈 페이지나
중복 항목 때문에 읽기 범위가 줄지 않는다. 150행을 넘긴 목록은 행 높이를
측정해 화면 근처만 그린다. 키보드로 다음 행·처음·끝까지 이동할 수 있다.
펼치지 않은 후보 묶음은 내부 행을 만들지 않고, 펼친 묶음은 50개씩 넘긴다.

기억의 검색·종류는 서버에서 찾는다. 후보·스킬의 검색·분류·같은 이름 묶음,
개수와 정렬은 불러온 목록 기준이다. 필터 결과가 0개여도 다음 서버 페이지가
있으면 ‘더 보기’를 유지한다. 전체 집계·전체 기준 정렬, 커서가 없는 다른
API에 새 페이지 계약을 추가하는 일은 완료 주장에 포함하지 않는다.
상세 구현과 검증 명령은 [목록 처리](list-performance.md)를 참고한다.

# Arkism 0.1.0

Arkism provides a shared memory and skill workspace for coding agents. Captured claims remain candidates until a person reviews them; approved memories retain their source context and can be reused across connected agents.

Windows installer: `Arkism-0.1.0-setup.exe`. This release note previously listed other OS formats as well; current release automation distributes Windows only.

Signing depends on configured certificates. Unsigned Windows packages may show SmartScreen confirmation. Keep existing data backed up before installing.

Storage runs locally when configured for built-in mode. Configured extraction can send conversation excerpts to the selected model provider; local storage does not imply all-local model processing.

Release automation requires correctness tests, the external Sonar quality gate, and package/runtime smoke checks for the same commit. Earlier wording did not establish published macOS/Linux artifacts; the current workflow packages Windows only. Database tests include backup and restore. These checks do not establish measured productivity improvement or completed real-user Claude/Codex acceptance testing.

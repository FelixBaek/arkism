# Arkism 0.1.0

Arkism provides a shared memory and skill workspace for coding agents. Captured claims remain candidates until a person reviews them; approved memories retain their source context and can be reused across connected agents.

Download the installer for your system:

- Windows: `Arkism-0.1.0-setup.exe`
- macOS (Apple silicon): `.dmg`
- Linux: `.AppImage` or `.deb`

Signing depends on configured certificates. Unsigned packages may show Windows SmartScreen or macOS Gatekeeper confirmation. Keep existing data backed up before installing.

Storage runs locally when configured for built-in mode. Configured extraction can send conversation excerpts to the selected model provider; local storage does not imply all-local model processing.

Release automation requires correctness tests, the external Sonar quality gate, and package/runtime smoke checks on Windows, macOS and Linux for the same commit. Database tests include backup and restore. These checks do not establish measured productivity improvement or completed real-user Claude/Codex acceptance testing.

# Security Policy / 보안 정책

## Reporting a vulnerability / 취약점 신고

Please do **not** open a public issue for a security problem.
Report it privately through GitHub: **Security → Report a vulnerability**
([new advisory](https://github.com/FelixBaek/arkism/security/advisories/new)).

보안 문제는 공개 이슈로 올리지 말아 주세요.
GitHub의 **Security → Report a vulnerability**([새 비공개 신고](https://github.com/FelixBaek/arkism/security/advisories/new))로 알려 주세요.

Include what you can / 가능하면 함께 적어 주세요:

- affected version or commit / 영향받는 버전 또는 커밋
- steps to reproduce / 재현 방법
- impact you expect / 예상되는 영향

You will get a first reply within 7 days. A fix is released as a new version, and the
advisory is published after the fix is out.

7일 안에 첫 답을 드립니다. 수정은 새 버전으로 배포하고, 배포 뒤에 공지를 공개합니다.

## Supported versions / 지원 버전

Only the latest release gets security fixes. / 보안 수정은 최신 릴리스에만 적용합니다.

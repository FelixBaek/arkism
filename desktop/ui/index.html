    이렇게 연결돼요

    1. 이 PC에서 ssh로 서버에 접속해요
    2. 서버 Arkism이 연결 정보를 알려 줘요
    3. SSH 터널로 이 앱과 이어요

    서버에서 따로 켜거나 포트를 열 것은 없어요. 키로 접속되는 SSH만 있으면 돼요.

    OpenSSH(또는 Git for Windows)가 이 PC에 있어야 해요.

A native plan preserves acceptance and observation clocks, including `native_zero`, `outside_int64_ns` and `not_recorded`. `server_return`, `context_delivery`, `actual_use` and `task_success` are independent observation states. Return or delivery never proves use or success. Unknown/pending emits no outcome event and consumes no evidence; it is not false. Explicit failure is not causal memory blame: non-memory attribution is non-learning. This module does not implement time decay or any DYN transition; no-event does not prohibit future configured decay.
